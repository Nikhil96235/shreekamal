1

Aapko kya karna hai

Doosre person ko apni repository me "collaborator" add karna. (Sirf 2 minute)

  1. github.com kholo aur apne account se login karo — wahi account jisme website ka code hai (username nikhil96235).
  2. Apni repository kholo. Upar search me shreekamal likho, ya seedha ye link kholo:
    https://github.com/nikhil96235/shreekamal
  3. Repository ke upar ki taraf kuch tabs honge (Code, Issues, Pull requests…). Sabse right taraf Settings (⚙️ gear icon) — us par click karo.
  4. Ab left side ki menu me neeche Collaborators par click karo. (Kabhi-kabhi "Collaborators and teams" likha hota hai.)
  5. GitHub aapse security ke liye password dobara maang sakta hai — daal do. (Ye normal hai, safety ke liye.)
  6. Green button Add people par click karo.
  7. Us person ka GitHub username ya email likho jise add karna hai. Neeche uska naam/photo aaye to us par click karo.
  8. Ab Add to repository button dabao. Bas ho gaya! Us person ko invite chala gaya.
Invite bhej diya — ab kya? Jab tak wo person accept nahi karta, uske naam ke aage "Pending" (yellow) dikhega. Accept karte hi wo "Collaborator" ban jayega. Aap chaho to usse baad me Remove bhi kar sakte ho isi Collaborators page se.

Doosre person ko kya karna hai

Invite accept karke code par kaam shuru karna.

  1. Uske paas ek GitHub account hona chahiye. Nahi hai to github.com par free me bana le — sirf email aur password.
  2. Invite accept karo: email me jo link aaya hai us par click kare, ya github.com par login karke upar-right kone me 🔔 (notifications / bell) me jaake invite accept kare.
  3. Accept karte hi wo poore code par kaam kar sakta hai. Ab do tarike hain (neeche dono diye hain).

Tarika A — Aasaan (chhote change ke liye)

github.com par repository kholo → jo file badalni hai us par click → upar pencil ✏️ icon dabao → edit karo → neeche Commit changes dabao. Bas, live ho jayega.

Tarika B — Aapke jaisa (VS Code se, proper kaam)

Ye tarika badे changes ke liye best hai — bilkul jaise aap karte ho:

  1. VS Code install kare (code.visualstudio.com se free).
  2. VS Code me GitHub se Sign in kare. (Left side "Accounts" icon ya prompt aayega.)
  3. Upar menu se View → Command Palette → likho "Git: Clone" → Enter.
  4. Repo ka link paste kare: https://github.com/nikhil96235/shreekamal
  5. Apne computer me ek folder choose kare jahan code save hoga.
  6. Ab file edit karke, neeche Source Control me message likh ke Commit + Sync kare. Bilkul jaise aap karte ho — change live ho jayega.
2 zaroori baatein (dono dhyan rakhein) 1) Collaborator ko apne aap "Write" access mil jata hai — matlab wo commit/sync kar sakta hai. Aapko alag se kuch set nahi karna.
2) Ek time par ek hi banda kaam kare (aap ya wo). Kaam shuru karne se pehle hamesha pehle Sync / Pull karo, taaki doosre ke naye changes pehle aa jayein — warna dono ke changes aapas me takra sakte hain.

❓ Kuch shabd — matlab kya hai

Repository (repo)
Aapki website ka poora code ek jagah — jaise ek online folder. Aapki repo ka naam shreekamal hai.
Collaborator
Wo person jise aap apni repo par kaam karne ki permission dete ho.
Commit
Aapne jo change kiya use "save" karna (ek chhota note ke saath).
Sync / Push / Pull
Sync = apne changes online GitHub par bhejna + doosre ke changes wapas laana. Kaam se pehle Sync karna best hota hai.
Clone
Online repo ki ek copy apne computer par download karna (taaki VS Code me kaam kar sako).
